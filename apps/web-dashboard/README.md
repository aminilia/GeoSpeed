# web-dashboard

React TypeScript dashboard for GeoSpeed sample/open-data-compatible speed-limit quality workflows.

## Pages

- Overview
- Map Explorer
- Segment Detail
- Quality Issues
- Release Readiness

The app uses mock API data in `src/mockData.ts` and MapLibre GL JS for road segment and sign visualization.

## Run

```bash
npm install
npm run dev
```

## Test

```bash
npm test -- --run
```
