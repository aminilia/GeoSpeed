# Roadmap Feedback Process

## From Request To Requirement

Partner requests enter triage, receive priority scoring, and convert into product requirements when they repeat or unlock launches.

## Priority Scoring

Score impact, urgency, partner reach, safety relevance, engineering cost, and roadmap alignment.

## Stakeholder Review

FDE, product, engineering, and partner leads review high-priority requests.

## Roadmap Influence

Requests can become experiments, committed roadmap items, documentation changes, or rejected proposals.

## Acceptance Criteria

Every accepted request needs user value, API or UI behavior, test data, and launch validation criteria.
