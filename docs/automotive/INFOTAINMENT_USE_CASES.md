# Infotainment Use Cases

## Navigation Speed-Limit Display

Render speed limit, unit, confidence, and current road segment in navigation context.

## Alert Rendering

Display non-blocking speed and stale-data warnings with clear status colors.

## Stale-Data Warning

Highlight stale or low-freshness speed-limit evidence before partner launch.

## Partner Debug Panel

Expose scenario ID, partner ID, issue flags, evidence sources, and owner team for FDE triage.
