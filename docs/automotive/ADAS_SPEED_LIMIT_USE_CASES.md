# ADAS Speed-Limit Use Cases

## Speed-Limit Assist

Show current inferred speed limit only when confidence and freshness are acceptable.

## Cruise-Control Mismatch

Flag when ADAS cruise-control set speed exceeds the road speed limit.

## Stale Speed-Limit Warning

Warn when map data is too stale for launch readiness.

## Missing Speed-Limit Fallback

Suppress legal speed display when no reliable source exists.

## Confidence-Based Warning Suppression

Avoid driver-facing warnings when confidence is too low for trusted display.
